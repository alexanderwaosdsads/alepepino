# ale pepino the game

Juego web (HTML/CSS/JS puro, sin dependencias).

- `index.html` – estructura
- `style.css` – estilos (ventana de Paint, minijuegos)
- `game.js` – toda la lógica (test, vasos, Flowey, esquivar pepinos, Peter, mazo)
- `assets/` – imágenes y audios (antes estaban incrustados en base64)

Probar: `python3 -m http.server 8000` y abrir http://localhost:8000
(usar servidor local, no doble clic, para que el audio con fetch funcione).
